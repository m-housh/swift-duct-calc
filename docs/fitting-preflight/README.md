# Historical artwork review records

These records preserve the checks, corrections, and approval decisions made
while importing the fitting artwork. They are not build inputs or an ongoing
review queue. Paths and hashes refer to the files at the time of each review;
removed source material and tooling remain in Git history.

The approved SVGs and catalog data are final checked-in assets. See
[finished fitting assets](../fitting-assets.md) for the current layout and checks.
