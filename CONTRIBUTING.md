Thanks for helping improve DuctCalc.

Please sign off each commit with your name and email using `git commit -s`. This is the Developer Certificate of Origin sign-off described at <https://developercertificate.org/>.

## Name and branding

The DuctCalc name, logo, domains, and other branding are not covered by the software license. Please do not use them to suggest that a modified version is the official DuctCalc project or that it is endorsed by the maintainers.

## Pull requests

Keep changes focused, explain the user-facing reason for the change, and include tests when behavior changes. If you are unsure whether a proposed change fits the project, open an issue first.
